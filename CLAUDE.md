# Instruções do projeto

## Documento de requisitos

`Quiz HxH — Qual é o seu tipo de Nen (Requisitos e Visão).md` é o documento vivo do projeto. A cada mudança no sistema, atualize-o no mesmo commit:

- requisitos novos ou alterados (RF/RNF), com critério de aceite
- modelo de dados, se surgir campo ou entidade
- uma seção "Fase N" para a entrega, com data, o que foi feito, testes e pendências em checklist
- números que mudaram (testes, personagens, perguntas)

## Commits

Não adicionar `Co-Authored-By` nem outra linha de autoria do Claude nas mensagens de commit.
